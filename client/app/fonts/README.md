# Bundled fonts

Inter and Fira Code Latin WOFF2 files were recovered unchanged from this project's existing Next.js font cache, preserving its typography while removing the build-time network dependency. Non-Latin glyphs fall back to system fonts.

Original projects: [Inter](https://github.com/rsms/inter), [Fira Code](https://github.com/tonsky/FiraCode). The adjacent OFL files include the copyright notices and redistribution licenses from the official Google Fonts repository.
