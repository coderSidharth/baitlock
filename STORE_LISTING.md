# Chrome Web Store submission materials

**Name:** Baitlock Phishing Shield

**Short description:** Check suspicious links and review phishing warnings with your Baitlock account.

**Description:** Baitlock checks web destinations using the API configured by your operator. It shows warnings for risky destinations, explains the reasons for a risk verdict and maintain your personal allow and block lists. Optional manual scans analyze visible page text. Detection is probabilistic and can miss threats or flag legitimate sites.

**Permissions:** `webNavigation` and `tabs` identify navigations and show warnings. `storage` keeps authentication and recent scan results. `activeTab` and `scripting` read visible text only after a manual scan. Host permissions are limited to the configured API and dashboard origins.

Existing icons are under `extension/icons/`. The operator must capture real screenshots from its configured deployment, provide a public reviewed privacy-policy URL and contact details, and complete the store's privacy disclosures before submission. Do not use placeholder deployment domains or invented product screenshots.
